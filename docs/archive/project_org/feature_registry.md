# Feature and Measurement Registry

## Production V4

V4’s strict point-in-time bundle uses the `prior_core` reference. Its concrete
Hydra feature groups and bundle configuration remain authoritative for the live
system; changes require the normal sealed evaluation and deployment workflow.

The absence of additive preseason families in V4 is intentional: any family
without pre-kickoff effective-time evidence for every required team-season is
not activation-eligible.

## Rating transition

The future rating system is organized around interpretable football measurement
families, not a broad matchup-feature registry. The canonical source is the
[measurement catalog](../modeling/measurement_catalog.md). A later measurement
contract will select the small, provenance-complete set used by the first rating
baseline and record its relationship to any V4 feature group.

Do not add rating candidates to V4 configuration, bundles, publication, or
rollback until a separate promotion contract authorizes it.
