# Session Closing Prompt (Compatibility Guide)

This historical prompt is retained for inbound links. Use the canonical [`end-session`](../../.agent/skills/end-session/SKILL.md) workflow instead.

Create a full session log for every planning, implementation, or fast-path session. Run validation scoped to the changed components and active implementation contract; do not broad-format or stage unrelated work in a dirty worktree. Git operations remain user-controlled.

For Sol planning sessions, save and validate the implementation contract before handing its exact path to a fresh Terra task. For Terra sessions, update the contract lifecycle and record any safe amendments or blockers.
