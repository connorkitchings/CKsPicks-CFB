# Session Start Prompt (Compatibility Guide)

This historical prompt is retained for inbound links. The canonical session workflow is now defined in [`AGENTS.md`](../../AGENTS.md) and the repository-local skills:

- [Start Session](../../.agent/skills/start-session/SKILL.md)
- [Plan Session](../../.agent/skills/plan-session/SKILL.md)
- [Implement Plan](../../.agent/skills/implement-plan/SKILL.md)
- [End Session](../../.agent/skills/end-session/SKILL.md)

Use `plan-session` for architectural, data/model, schema, production, security, or multi-component work. Persist approved contracts at `docs/plans/YYYY-MM-DD/`, then open a fresh Terra task for implementation. Use the fast path for established localized changes.
