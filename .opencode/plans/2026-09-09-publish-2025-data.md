### Phase 2: Publish 2025 Data to Database

**Prerequisites:** Phase 1 confirms artifacts exist.

#### Step 2a: Publish 2025 Predictions

For each week with prediction artifacts:

```bash
# Publish a single week
PYTHONPATH=. uv run python scripts/pipeline/publish_to_db.py \
  --year 2025 \
  --week <WEEK> \
  --from-artifact \
  --run-id <RUN_ID> \
  --no-update-current \
  --state published

# Example for week 1:
PYTHONPATH=. uv run python scripts/pipeline/publish_to_db.py \
  --year 2025 \
  --week 1 \
  --from-artifact \
  --run-id 2025w1-abc123 \
  --no-update-current \
  --state published
```

**Key flags:**
- `--from-artifact`: Read from R2 instead of local CSV
- `--run-id`: Specific immutable run ID (from manifest)
- `--no-update-current`: Don't update current_week singleton (2026 is active)
- `--state published`: Set run state to "published" (not frozen/scored yet)

#### Step 2b: Publish 2025 Scored Results

For each week with scored artifacts:

```bash
# Backfill all scored weeks for 2025
PYTHONPATH=. uv run python scripts/pipeline/score_to_db.py \
  --year 2025 \
  --backfill-season \
  --from-artifact
```

This will:
- Upsert game results to `game_results` table
- Recompute `system_stats` for 2025
- Enable win/loss tracking in the web app

#### Step 2c: Freeze and Score Prediction Runs

After publishing predictions and results, update run states:

```python
# Python script to update run states
import psycopg
from dotenv import load_dotenv
import os

load_dotenv()
conn_url = os.environ["DATABASE_URL"]

with psycopg.connect(conn_url) as conn:
    with conn.cursor() as cur:
        # Freeze all 2025 prediction runs
        cur.execute("""
            UPDATE prediction_runs 
            SET state = 'frozen', frozen_at = NOW()
            WHERE season = 2025 AND state = 'published'
        """)
        print(f"Froze {cur.rowcount} prediction runs")
        
        # Score runs that have results
        cur.execute("""
            UPDATE prediction_runs pr
            SET state = 'scored', scored_at = NOW()
            FROM games g
            JOIN game_results gr ON g.game_id = gr.game_id
            WHERE pr.season = 2025
              AND pr.state = 'frozen'
              AND pr.run_id = g.run_id
              AND gr.home_points IS NOT NULL
        """)
        print(f"Scored {cur.rowcount} prediction runs")
        
    conn.commit()
```

### Phase 3: Generate 2025 Predictions (If Artifacts Don't Exist)

**Prerequisites:** Phase 1 shows no 2025 artifacts exist.

**Steps:**

1. **Generate 2025 predictions using V4 model:**
   ```bash
   # For each week in 2025
   for week in {1..15}; do
     PYTHONPATH=. uv run python scripts/pipeline/generate_weekly_bets.py \
       --year 2025 \
       --week $week \
       --config conf/weekly_bets/v4_2026.yaml \
       --output-dir artifacts/production/predictions/year=2025/week=$week/
   done
   ```

2. **Score the predictions against actual results:**
   ```bash
   # Score each week
   for week in {1..15}; do
     PYTHONPATH=. uv run python scripts/pipeline/score_weekly_bets.py \
       --year 2025 \
       --week $week
   done
   ```

3. **Publish to database:** Follow Phase 2 steps.
