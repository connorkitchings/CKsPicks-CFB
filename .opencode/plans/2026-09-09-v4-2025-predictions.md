## Implementation Plan: Week-by-Week V4 Inference for 2025

### Phase 1: Fetch Missing Betting Lines

### Phase 2: Build Week-by-Week Silver/Gold Datasets

**Goal:** For each week 1-16, build feature datasets using only data before that week's kickoff.

**Challenge:** The `prepare-week` pipeline is designed for 2026's structure (with week 0). We need to adapt it for 2025.

**Approach:** Create a custom script that:
1. For each week N (1-16):
   - Load 2021-2024 data (training data)
   - Load 2025 weeks 1 to N-1 (completed games)
   - Load 2025 week N schedule (upcoming games)
   - Build features using only this data
   - Run V4 inference
   - Store predictions

**Key functions:**
- `build_temporal_matchup_inputs()` - builds wide matchup features
- `build_point_in_time_matchups()` - converts to team-keyed rows
- `predict_with_model_bundle_v3()` - runs V4 model inference
- `calculate_edges_and_leans()` - calculates edges vs betting lines

**Pseudocode:**
```python
for week in range(1, 17):
    # Load data available before week N
    schedule_2025 = load_schedule(2025)
    schedule_2021_2024 = load_schedule([2021, 2022, 2023, 2024])
    outcomes_2021_2024 = load_outcomes([2021, 2022, 2023, 2024])
    outcomes_2025_completed = load_outcomes(2025, weeks=range(1, week))
    
    # Build team-game stats
    team_game = build_team_game_stats(
        schedule_2021_2024 + schedule_2025,
        outcomes_2021_2024 + outcomes_2025_completed
    )
    
    # Build temporal matchups for week N
    matchups = build_temporal_matchup_inputs(
        schedule=schedule_2025[schedule_2025.week == week],
        team_game=team_game,
        prior_2019=load_prior_2019(),
        outcomes=outcomes_2021_2024 + outcomes_2025_completed,
        inference_seasons={2025}
    )
    
    # Build point-in-time features
    features = build_point_in_time_matchups(
        matchups,
        season=2025,
        as_of=week_N_kickoff_time,
        provenance={...}
    )
    
    # Load V4 model bundle (selection-time, trained on 2021-2024)
    bundle = load_model_bundle_v3(...)
    
    # Run inference
    predictions = predict_with_model_bundle_v3(bundle, features)
    
    # Load betting lines for week N
    lines = load_betting_lines(2025, week)
    
    # Calculate edges/leans
    predictions_with_edges = calculate_edges_and_leans(predictions, lines)
    
    # Store predictions
    store_predictions(2025, week, predictions_with_edges)
```

**Challenge:** The V4 production bundle is trained on 2021-2025 (production refit). We need the selection-time model (trained on 2021-2024 only).

**Solution:** The V4 benchmark recovery already has the selection-time model. We need to locate and use that model bundle instead of the production bundle.
