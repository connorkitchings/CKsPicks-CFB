## Context and Decisions
- Step-timing breakdown of run `36332052526`: setup/install ~70s, ruff ~1s, pytest 732s, contracts skipped (pytest failed first). The test step is 99% of the runtime.
- Suite is parallel-safe except `tests/test_migration_integration.py` (2 tests DROP/CREATE shared `public`/`ops`/`catalog` schemas on the single service DB). `--dist loadfile` keeps each file's tests on one worker, so those two stay sequential. Everything else mocks `psycopg`/env per test.
- Splitting lint/format/contracts into their own job also fixes contracts validation being skipped whenever tests fail, and gives a ~1 min early signal.
- `pytest-xdist v3.8.0` (+ `execnet`) added to the `dev` dependency-group; `uv.lock` regenerated in the same change so `uv sync --frozen` keeps working.
