## Technical Notes

### Backward Compatibility Pattern
New aggregation specs in `core.py` use conditional dicts:
```python
_off_optional: dict = {}
if "turnover" in plays_df.columns:
    _off_optional["off_turnover_rate"] = ("turnover", "mean")
# ... etc.
off_agg = off_grp.agg(..., **_off_optional)
```
This ensures existing unit tests (which don't provide all columns) continue to work, while the full pipeline (which always runs through byplay.py) gets all new features.

### Vectorization Approach
- `update_yards_gained`: Direct `np.where()` with string contains checks
- `calculate_play_success`: `np.select()` with compound boolean conditions
- `calculate_explosive`: Direct numpy array with boolean indexing
- Original row-wise helper functions retained for documentation/reference
