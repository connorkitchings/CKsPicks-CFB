# Session Log Archive

This archive preserves every historical session log while keeping the parent
directory focused on the current month's work.

- `daily/YYYY-MM-DD/` contains dated session logs before 2026-10-01, including
  the normalized 2025 and early-2026 history, all of August 2026 (archived
  2026-10-01) and all of September 2026 (archived in the repository
  consolidation of 2026-10-22). References were rewritten and verified.
- `weekly/` contains older aggregate weekly summaries.
- `historical_summary_through_2025-10.md` is a legacy summary whose statements
  are historical, not current authority.

The parent `session_logs/` directory contains 2026-10-01 and newer work. This
archive is maintained manually; no rolling archival automation exists.
