# Session Logs

Session logs are chronological engineering evidence, not current architecture
authority. Start with repository onboarding and the documentation home, then
read logs only when their historical context is relevant.

## Active window

Logs dated **2026-08-09 and later** remain directly under this directory.
Logs before that date are retained under `archive/daily/YYYY-MM-DD/`.

The cutoff is a manual documentation-maintenance policy, not automation. Keep
using `YYYY-MM-DD/NN-descriptive-slug.md` for new session logs and retain
`TEMPLATE.md` as the only active template.

See [the archive index](archive/README.md) for historical layout.
